# QA Lacrei Saúde

## 📌 Sobre o projeto
Projeto de Quality Assurance focado em validação de fluxos críticos da plataforma Lacrei Saúde.

---

## 🎯 Objetivo
Garantir qualidade funcional, acessibilidade, performance, responsividade e automação dos principais fluxos.

---

## 🧪 Escopo de testes
- Testes funcionais (Gherkin)
- Testes manuais exploratórios
- Testes automatizados (Cypress)
- Testes de performance (Lighthouse)
- Testes de acessibilidade
- Testes de responsividade

---

## 🧱 Estrutura do projeto
- /docs → documentação QA
- /cypress → testes automatizados
- /.github → CI/CD pipelines

---

## ⚙️ Tecnologias
- Cypress
- Cucumber (Gherkin)
- GitHub Actions
- Lighthouse
